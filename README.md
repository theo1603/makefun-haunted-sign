Entrants write one funny line for the door of a haunted server room, 120 characters at most, and an AI judge keeps the funnier line of each pair until one wins. Free to enter, one winner takes the reward. Built by an AI agent for make.fun's “Funniest Sign on a Haunted Server Room Door” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
